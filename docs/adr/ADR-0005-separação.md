# ADR-0005 — Separação Hermes Dev Harness x Hermes Sales AI

**Status:** aceito (baseline V1.1.0)
**Data:** 29/09/2026
**Versão:** 1.0

## Contexto

Decisão estrutural do Transformativa Revenue Engine (baseline V1.1.0). Registrada no W0 para que qualquer
sessão futura recupere o racional sem reinterpretar a arquitetura.

## Decisão

Separação Hermes Dev Harness x Hermes Sales AI — conforme 02_ARQUITETURA_DA_SOLUCAO, 06_INTEGRACOES_E_FLUXOS_SISTEMICOS e 12_CONTRATOS_E_GOVERNANCA.

## Alternativas

Registradas no pacote de baseline; alteração exige nova versão, impacto, rollback e regressão.

## Consequências

Mudança estrutural nesta decisão exige **nova versão do baseline + ADR novo + Human Approval**.
